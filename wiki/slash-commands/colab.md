# /colab

[Accueil](Home.md) · [Wiki interactif](index.html#colab)

Gérer la collaboration de plusieurs IA.

## Syntaxe du catalogue

```text
/colab [action]
```

| Argument | Obligatoire | Description du catalogue |
| --- | --- | --- |
| action | Non | status, tasks, start \<id\>, complete, log, handoff, init, instructions |

## Recette : TESTE\_LOCAL

```text
/colab status
```

/colab status (consultation de l'état de collaboration et règles).

Attendu : Statut du workflow de collaboration multi-IA

[Capture locale](../../../../Videos/Partage/20260914-commandes-wiki/cases/colab/terminal.txt)

## Invocation prévue

```text
/colab status
```

Cette invocation vient du plan ; sa présence ne prouve pas son exécution.

## Limites

Le verdict porte sur l’invocation capturée, pas sur toutes les sous-commandes. Une aide affichée ne valide pas une connexion, une modification, ni un appel IA. Les résultats Linux ne prouvent pas le fonctionnement Windows. Sans preuve, la commande reste NON_TESTE.
