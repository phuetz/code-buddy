# /explain

[Accueil](Home.md) · [Wiki interactif](index.html#explain)

Faire expliquer du code ou un fichier.

## Syntaxe du catalogue

```text
/explain [file]
```

| Argument | Obligatoire | Description du catalogue |
| --- | --- | --- |
| file | Non | File path to explain |

## Recette : VALIDATION\_SEULE

```text
/explain
```

validation et demande de confirmation du fichier cible à expliquer.

Attendu : Affichage du sélecteur ou validation des arguments/prérequis ; action complète non validée.

[Capture locale](../../../../Videos/Partage/20260914-commandes-wiki/cases/explain/terminal.txt)

## Invocation prévue

```text
/explain
```

Cette invocation vient du plan ; sa présence ne prouve pas son exécution.

## Limites

Le verdict porte sur l’invocation capturée, pas sur toutes les sous-commandes. Une aide affichée ne valide pas une connexion, une modification, ni un appel IA. Les résultats Linux ne prouvent pas le fonctionnement Windows. Sans preuve, la commande reste NON_TESTE.
