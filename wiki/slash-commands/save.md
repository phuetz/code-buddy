# /save

[Accueil](Home.md) · [Wiki interactif](index.html#save)

Enregistrer la conversation dans un fichier Markdown.

## Syntaxe du catalogue

```text
/save [filename]
```

| Argument | Obligatoire | Description du catalogue |
| --- | --- | --- |
| filename | Non | Output filename (optional, defaults to timestamp) |

## Recette : TESTE\_LOCAL

```text
/save conversation.md
```

Fichier Markdown de 23 049 octets créé ; la relecture confirme la présence de l’aide dans la conversation exportée.

Attendu : Sauvegarde de la conversation courante dans un fichier markdown

## Invocation prévue

```text
/save conversation.md
```

Cette invocation vient du plan ; sa présence ne prouve pas son exécution.

## Limites

Le verdict porte sur l’invocation capturée, pas sur toutes les sous-commandes. Une aide affichée ne valide pas une connexion, une modification, ni un appel IA. Les résultats Linux ne prouvent pas le fonctionnement Windows. Sans preuve, la commande reste NON_TESTE.
