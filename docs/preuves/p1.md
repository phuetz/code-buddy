Le correctif `a8dc11fb2` choisit un agent enregistré (`coder`) lorsque le rôle planifié est absent. Test rouge : 1 échec sur 2 avant le correctif ; vert : 2/2 après ; mutant supprimant le repli : 1 échec sur 2 ; essaim réel : `Success: yes`, 38 s, lecture de `indice.txt` et réponse « indigo ». `npm run typecheck` et ESLint ciblé ont terminé avec statut 0. Ce correctif ne prouve pas la justesse de tous les plans ni de tous les rôles possibles.
