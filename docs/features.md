# Source areas and evidence limits

Code Buddy is a terminal coding agent with local and optional cloud model routing.
Its release criterion is a fresh installation with a small tool-calling model and a
verified first task. That criterion remains unproven on this branch.

The generated [feature index](feature-catalog.md) and [detailed status page](PROVEN-FEATURES.md)
are the authority for showcase statuses and totals. A provider name, tool definition,
static wiring check or configuration command is not proof of its user outcome.

| Source area | Documentation | Evidence boundary |
|---|---|---|
| Agent tools and model routing | [Tools](tools-reference.md), [providers](providers.md) | Success summaries without captured exchanges remain unproven here. |
| Context and memory | [Context](context-engine.md), [memory](learning-mechanisms.md) | Component compression is proved for its fixture; this does not validate a full agent session. |
| Security | [Permissions and sandbox](security.md) | One Linux bubblewrap component probe is proved, not all commands or platforms. |
| Desktop and peer interfaces | [Cowork](cowork.md), [fleet](fleet-guide.md) | No current showcase proof of these end-to-end interfaces. |
| Voice, perception and media | [Detailed statuses](PROVEN-FEATURES.md) | Configuration is not speech; simulated Telegram is not public delivery; latest video-understanding attempt failed. |
| Experimental proposals | [Mechanisms](learning-mechanisms.md) | Rollback, rejection or an empty archive is not a retained improvement. |

Existing source documentation describes intended behavior and activation conditions.
It does not extend the proven scope. No provider/tool/platform count, competitor
performance comparison or productivity gain is used as a showcase claim here.
