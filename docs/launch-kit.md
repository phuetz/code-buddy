# Launch kit — October 8 candidate wording

These are drafts for the local-first angle. The release criterion is a fresh installation with a small local model, a first coding task and verification of the result. **That criterion is not proven by the traces on this branch.** Review the [current evidence catalogue](PROVEN-FEATURES.md) before publishing; these drafts do not authorize publication.

The catalogue is the source for statuses and counts. Historical demos, test totals, provider lists and tool definitions are not fresh-installation evidence. Cowork, fleet, voice, video and learning remain **not proven here**, with reasons in the catalogue.
