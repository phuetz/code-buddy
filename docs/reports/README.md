Ces rapports conservent les preuves des lanes, audits, réparations, revues, bilans et bancs exécutés.
Le nom d’origine est conservé (`RAPPORT-`, `REPARATION-`, `REVUE-`, `AUDIT-`, `BILAN-` ou `BANC-`), classé par mois d’ajout.
Les nouveaux rapports vont dans `docs/reports/<AAAA-MM>/`, avec leurs références mises à jour dans le même lot.
