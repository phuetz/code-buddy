## Quatre causes résiduelles : preuves et échéance

Chaque entrée du JSON possède son **paquet, ses URL d’avis (y compris hérités), tous ses nodes, reviewedOn=2026-10-03, motif et reviewBy=2026-10-14**. Les parents sont nommés individuellement dans le tableau et le JSON, avec la chaîne qui explique la gravité ; aucune exception universelle, aucun `|| true`, aucun recul du seuil de CI. Les anciens identifiants d’avis qui ne correspondaient plus aux avis réels ont été remplacés.

1. **braces 3.0.3 / GHSA-vfj7-8cjw-p6xm** : [aucune version corrigée](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm). Le risque porte sur des AST profondément imbriqués. Les neuf consommateurs runtime de fast-glob ont été reliés à `src/utils/safe-fast-glob.ts`. Cette frontière vérifie **avant parsing** les motifs positifs, négatifs et `ignore` : longueur ≤4096, nombre ≤1024 et nombre conservateur d’ouvertures `{`/`(` ≤64. Les APIs async, glob, sync, stream, generateTasks et isDynamicPattern restent gardées ; objectMode/stats et les alternatives normales sont vérifiés réellement. Les motifs complexes sont désormais refusés avec une erreur lisible. L’exception sur la copie partagée concerne aussi des consommateurs hors CLI : les motifs de semantic-release viennent de `.releaserc.json` (`main`, assets nommés et `*.tgz`) et du manifeste de publication ; les scripts de maintenance utilisent des motifs écrits dans leur source. Metro/Jest viennent de la chaîne optionnelle alasql → react-native-fs → react-native. AlaSQL sonde React Native sous try/catch, mais le CLI Node ne lance pas le bundler ni Jest. `micromatch-chemins.json` contient les consommateurs installés ; aucun autre consommateur de cette copie n’est écarté sans explication. Revoir à la sortie corrigée de braces ou changement de frontière glob.
2. **http-cache-semantics 4.2.0 / GHSA-ch52-4w7c-c8xp** : [aucune version corrigée](https://github.com/advisories/GHSA-ch52-4w7c-c8xp). La seule copie est `node_modules/npm/node_modules/http-cache-semantics` (semantic-release → plugin npm → npm, développement). `npm/node_modules/make-fetch-happen/lib/cache/policy.js` construit CacheSemantics avec `shared:false` (lignes 6-8, construction ~50). Le scénario de sessions d’autres utilisateurs implique un cache partagé et un `max-stale` fourni par le client ; les routes HTTP de Code Buddy ne consultent pas ce cache privé npm et ne lui transfèrent aucun Cache-Control client. `cache-chemins.json` donne les chaînes exactes. Retirer lorsque npm embarque le correctif ; revoir si une route expose ce cache.
3. **brace-expansion 5.0.9 embarqué par npm 11.19.1** : correctifs 5.0.10/11/12 disponibles selon les trois avis ; les copies hors bundle sont déjà corrigées. L’override ne modifie pas le bundle npm. Le tarball npm 11.21.0 inspecté garde également 5.0.9 ; aucun downgrade arbitraire de semantic-release. L’usage de ce npm est la publication par CI avec des motifs fixés par `.releaserc.json`/`package.json`, pas des motifs client profonds ou de longues listes récursives. Scope unique `node_modules/npm/node_modules/brace-expansion`. Retirer avec un bundle corrigé.
4. **undici 6.28.0 embarqué par npm → node-gyp** : correctif 6.28.1 disponible ; copie runtime 6.29.0 corrigée, scope de dérogation uniquement `node_modules/npm/node_modules/undici`. `node-gyp/lib/download.js` importe Agent, EnvHttpProxyAgent, RetryAgent et fetch, jamais WebSocket : l’avis high sur les sous-protocoles et le moderate de décompression WebSocket n’atteignent pas ce chemin. Il emploie bien RetryAgent ; l’avis low connexe est documenté en distinguant le téléchargement de fichiers de l’exposition d’un proxy HTTP de réponses, absent de cet usage. npm 11.21.0 conserve aussi 6.28.0. `preuve-bundles-npm.json` contient les versions des distributions 11.19.1 et 11.21.0 réellement inspectées. Retirer avec un bundle corrigé.

Le gate exige désormais les **URL précises**, une revue datée et un motif, et refuse un résultat npm incomplet/erreur réseau. Les restrictions de nodes restent appliquées aux instances vulnérables. Les URL héritées sont traversées avec détection des cycles : une nouvelle faille sur un enfant d’un paquet autorisé est refusée. Les critiques restent inconditionnellement bloquants. Tests : nouvelle copie runtime refusée, avis nouveau direct/hérité refusé, exception expirée/incomplète refusée et erreur npm refusée.
