A local-first coding agent.

Repository tools, configurable model routing and optional desktop and peer interfaces. Their presence in the source does not establish their user outcomes.

The release criterion is a fresh installation with a small local model and a first task checked independently. This is not proven here.

Read the scenario limits.

The catalogue accepts component traces for context compression and a Linux bubblewrap sandbox fixture. Those narrow checks do not validate the full agent loop, Cowork, fleet, voice, companion or video outcomes.

Configuration, screenshots and a successful process exit do not extend that scope. The generated catalogue is the authority for current statuses.

Configure and inspect a task.

npm install -g @phuetz/code-buddy
buddy onboard
buddy doctor
buddy try

CLI: Node ≥ 20. Cowork: Node ≥ 22. The demo requests a task; inspect its files and run project checks independently. Duration and result depend on the configured model and environment.
